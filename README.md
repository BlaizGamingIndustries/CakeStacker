# Birthday Cake Stacker Extreme!

A browser-based arcade stacking game made with HTML, CSS, and JavaScript.

## Play the Game
https://blaizgamingindustries.github.io/CakeStacker/

## About
Stack birthday cake layers as high as possible without dropping them.

## Features
- Arcade-style gameplay
- Score tracking
- Animated graphics
- Mobile-friendly controls
- Retro UI styling

## Built With
- HTML5
- CSS3
- JavaScript
